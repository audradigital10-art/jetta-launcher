# Jetta Launcher

Tela inicial personalizada (tema escuro esportivo) para a multimídia Android do VW Jetta (tela 7", 1024x600, Android 13).

## Baixar e instalar pelo Wi-Fi

1. Na multimídia, abra o navegador e acesse:
   `https://github.com/audradigital10-art/jetta-launcher/releases/latest/download/JettaLauncher.apk`
2. Abra o arquivo baixado e toque em **Instalar**. Se pedir, permita "instalar apps desconhecidos" para o navegador.
3. Aperte o botão **Home** e escolha **Jetta Launcher** → **Sempre**.

Atualizações: repita os passos 1 e 2. As personalizações são mantidas.

## Como usar

- **Toque** em um bloco para abrir o app.
- **Toque longo** em um bloco: trocar o app, renomear, mudar a cor, usar o ícone do app ou restaurar o padrão.
- **Todos os aplicativos**: lista completa. Toque longo num app para renomear, ocultar, ver informações ou desinstalar.
- **Toque longo no relógio**: cor principal do tema, texto do topo, definir como tela inicial padrão.

## Voltar para a tela original

Configurações → Apps → Apps padrão → App de tela inicial → escolha a tela original da central.

## Compilação

Cada envio para `main` compila o APK automaticamente (GitHub Actions) e publica em *Releases*.
